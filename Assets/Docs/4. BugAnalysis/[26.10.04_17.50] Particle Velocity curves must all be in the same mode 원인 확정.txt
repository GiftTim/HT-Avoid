b. 문제점
================================================================

  Play 중 콘솔에 아래 오류가 나온다.

    Particle Velocity curves must all be in the same mode

  Velocity over Lifetime 의 x / y / z 세 곡선이 서로 다른 모드일 때
  Unity 가 내는 오류. 가속 연출(바람 자국)의 속도가 의도대로 적용되지
  않을 수 있고, 로그가 반복해서 쌓일 수 있다.


================================================================
c. 현재 상황 및 코드
================================================================

  [ PlayerSpeedAura.cs — CreateTrail() 129~134행 ]
    velocity.x = 0;                 // float → Constant 모드
    velocity.y = 0;                 // float → Constant 모드
    velocity.z = -REFERENCE_SPEED;  // float → Constant 모드  (여기까진 일치)

  [ PlayerSpeedAura.cs — SetFlowSpeed() 90~94행, 매 프레임 Update 에서 호출 ]
    velocity.z = new ParticleSystem.MinMaxCurve(-max, -min);
                                    // float 두 개 → TwoConstants 모드

  → 왼쪽/오른쪽 바람 자국(leftTrail / rightTrail)은 x, y 가 Constant 인데
    z 만 TwoConstants 가 되어 세 곡선의 모드가 어긋난다.
    Start 직후 첫 Update 부터 매 프레임 발생.

  [ 정상인 곳 ]
  - CreateDust() 173~175행 : x, y, z 모두 MinMaxCurve(min, max)
    → 모두 TwoConstants, SetFlowSpeed 로 z 를 갱신해도 계속 일치
  - SpeedEffect.cs 118~123행 : x, y, z 모두 float → 모두 Constant (일치).
    갱신하는 코드도 없음

  ※ 이 판단은 코드를 읽고 내린 것이다. 콘솔 스택트레이스는 이번에
    직접 확인하지 못했다 (현재 에디터 콘솔에는 이 메시지가 남아 있지
    않았음).


================================================================
d. 해결을 위해 생성하거나 변경해야 하는 내용
================================================================

  바람 자국(Trail)의 x, y, z 세 곡선을 모두 TwoConstants 로 통일한다.

  CreateTrail():
    velocity.x = new ParticleSystem.MinMaxCurve(0, 0);
    velocity.y = new ParticleSystem.MinMaxCurve(0, 0);
    velocity.z = new ParticleSystem.MinMaxCurve(-REFERENCE_SPEED, -REFERENCE_SPEED);

  SetFlowSpeed() 는 그대로 (z 를 TwoConstants 로 갱신하므로 일치 유지).


================================================================
e. 다른 방법들 중에서 왜 d의 방식으로 만든 것인지
================================================================

  [ 대안 1 : SetFlowSpeed 에서 z 를 Constant 로 갱신 ]
  - 바람 자국은 min == max 라서 가능하지만, 먼지는 min != max 라
    SetFlowSpeed 를 둘로 나누거나 분기를 넣어야 함. 변경이 더 커짐

  [ 대안 2 : SetFlowSpeed 에서 x, y, z 를 매번 모두 대입 ]
  - 항상 일치는 하지만 매 프레임 불필요한 대입이 늘어남

  [ 채택 : 생성 시점에 x, y 를 TwoConstants 로 통일 ]
  - 수정이 CreateTrail 3줄뿐이고, 먼지(CreateDust)와 같은 형태가 되어
    코드 일관성도 좋아짐. 연출 결과(속도)는 변하지 않음


================================================================
f. 어떤 순서로 진행할 것인지
================================================================

  1. PlayerSpeedAura.CreateTrail 의 velocity x / y / z 3줄 수정
  2. Unity 컴파일 확인 후 콘솔 Clear
  3. Avoid.unity Play : 앞 방향키로 가속 → 오류가 다시 나오지 않는지,
     바람 자국이 이전과 같이 흐르는지 확인
  4. 이상 없으면 Record 에 한 줄 기록

h. 주의할 점
================================================================

  ■ MinMaxCurve(float) 는 Constant, MinMaxCurve(float, float) 는
    TwoConstants 이다. 한 모듈의 x / y / z 는 반드시 같은 모드로 맞출 것.
    앞으로 Velocity 를 코드로 바꿀 때도 동일

  ■ SetFlowSpeed 로 값을 갱신하는 시스템은 생성 시점의 모드와 갱신 시의
    모드가 같아야 함 (이번 오류의 직접 원인)

  ■ 수정 후에도 오류가 남으면 velocity.x.mode / y.mode / z.mode 를
    로그로 찍어 확인할 것

  ■ 16.41 문서의 "enabled 를 마지막으로 옮긴다"는 방법은 이번 원인과
    무관하므로 적용하지 않음
