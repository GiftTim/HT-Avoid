[오늘 한 일 요약]

  일정표 10.05 분량. 계획은 ChangePlan [26.10.04_23.40], 결과는 그 문서의
  i절. 3단계로 진행했고 앞 두 단계는 끝까지, 세 번째는 데이터/패턴까지.

  1. VN 설정창 (SettingsPanel)
     - 항목 : 전체/배경음/효과음 볼륨, 텍스트 속도, 오토 속도 (기본안)
     - VN Menu 버튼 / Esc / 패드 Start 로 열고, Esc / Start / 패드 B 로 닫음
     - UI 는 코드로 만든 임시 UI(한글 폰트 적용). 방향키/패드로 조작
     - Main.mixer 에 볼륨 파라미터 3개 노출, 값은 PlayerPrefs 저장
  2. 피하기 일시정지 연동
     - 같은 설정창을 피하기 중에도 열림. 열려 있는 동안 timeScale 0,
       피하기 조작 무시, 닫으면 이어짐. 클리어/시간 초과 연출 중에는 안 열림
     - 클리어 후 VN 으로 돌아오면 VN 입력/timeScale 이 정상으로 복구됨
  3. 1스테이지 (StageProfile + StageRunner)
     - Resources/Stages/Stage1.asset : 제한시간 60 / 600m / 패턴 27개
     - 패턴 4종 : 낮은(멈춤) / 높은(넉백) / 감속 / Wall(한 칸 비움)
     - "진행 거리 → 패턴" 목록, 장애물은 월드에 고정. AttackSpawner 대체
     - startAvoid(Stage1) 로 프로필 선택 (대본 AvoidChapterTest 에 연결)
     - 시간 초과 시 진행률/남은 패턴 수를 AvoidSession 에 기록
       (컵헤드식 실패 화면은 나중에 이 값을 읽어 표시)


[이번에 내린 결정과 이유]

  - 설정창 열기/닫기 입력은 PlayerInput 이 아니라 SettingsPanel 안의
    InputAction 으로 처리 (피하기 중 VN 입력이 꺼져 있어도 열려야 하고,
    입력 컴포넌트 껐다 켜는 방식과 엮이지 않게). AvoidInput 에 Pause 액션
    은 추가하지 않음
  - 일시정지는 timeScale 0 (이동/시간/스크롤이 전부 deltaTime 기반)
  - 패턴을 월드 고정 + 거리 기준으로 (진행률/남은 패턴 수 계산이 쉬움)
  - 사용자 지정이 없던 항목(설정창 항목, 패턴 종류)은 기본안으로 진행.
    바꾸고 싶으면 알려 달라고 함

  프로필 적용(60초/600m/27개), 시간 초과 시 기록, startAvoid(Stage1)
