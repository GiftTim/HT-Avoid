  1. 캐릭터 주변 가속 이펙트 추가 (Scripts/Avoid/Core/PlayerSpeedAura.cs)
     - 가속(GameController.AccelerationRatio)에 비례해
       · 캐릭터 양옆 허리 높이에서 흐릿한 하얀 바람 자국이 뒤로 흐름
       · 발밑에서 먼지가 일어남
     - 파티클은 코드로 생성 (별도 에셋 없음). 부드러운 원형 텍스처도
       코드로 생성
     - 흐르는 속도는 GameController.StageSpeed 를 따름
       (바람 자국 = StageSpeed x trailSpeedRatio, 먼지 = 바닥 속도 그대로)
     - 기존 SpeedEffect(화면 전체 속도선 + FOV)는 그대로 두고 병행
     - 참고 이미지 : 테일즈 러너의 가속 장면 (양옆 하얀 바람 자국 + 발밑 먼지)
     - Avoid.unity 의 Player 오브젝트에 컴포넌트 부착
     - 첫 버전(캐릭터를 둘러싼 링 모양 줄기)은 레퍼런스와 달라서 폐기


[나중에 할 것 — 보류 (사용자가 생각해 보기로 함)]

  ★ 바닥을 구간(Segment) 프리팹 방식으로 바꾸는 것

  - 문제 : 지금 바닥은 Plane 하나의 텍스처 UV 만 스크롤(GroundScroller)
    해서 "걷는 느낌"을 낸다. 바닥이 항상 사각형 한 장이라
      · 길이 좁아지는 구간
      · 중간에 바닥이 없는 외길(구멍/다리)
    을 만들 수 없다.

  - 제안한 해결 방향
    1) 바닥을 구간 프리팹으로 나눠 앞쪽에서 생성하고 StageSpeed 로
       플레이어 쪽으로 흘려보냄 (ScenerySpawner/ApproachingObject 가
       이미 같은 방식이므로 재사용 가능)
    2) 길 모양 : 구간마다 폭이 다른 프리팹, 끊긴 구간은 바닥 없는 프리팹
    3) 좁은 길 : 구간이 폭 정보를 갖고, 플레이어가 서 있는 구간 폭으로
       AvoidPlayerMovement.limitX 를 동적으로 변경 (지금은 고정값)
    4) 바닥 없는 구간 : 점프로 건넘. 떨어지면 죽지 않고 시간 손실 +
       복귀 (기존 피격 반응 = 멈춤/넉백과 같은 방식으로 처리)
       바닥 판정은 아래로 레이캐스트 또는 구간 콜라이더 위 여부
    5) 가속 이펙트 : 발밑 먼지는 "바닥 위에 있을 때만" 나오도록
       IsGrounded 연결 필요

  - 결정 대기 : 구간 프리팹 방식으로 갈지 / 다른 방법이 있는지
  - 일정 영향 : 목표 완성일 10.08. 첫 챕터부터 길 모양 변화가 필요한지
    정해야 함. 필요 없으면 챕터 양산 후로 미뤄도 됨
  - 확정되면 로드맵(1. Plan)에 반영할 것
