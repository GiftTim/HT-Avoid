[오늘 한 일 요약]

  지난 세션(0915 커밋 "점프/그라운드 레이어 버그 수정 + 리스폰 존
  추가")까지 이동(WASD+점프)만 있던 상태에서, 조준/공격까지 붙여
  "카타나 제로 모티브 기본 인터페이스"를 완성함.

  1. AimCursor 안 보이는 버그 수정
     - 원인 1 : Canvas-Main의 RectTransform m_LocalScale이 {0,0,0}으로
       들어가 있어서 그 아래 6-Controls → LAYERS → AimCursor 전체가
       크기 0으로 접혀 있었음 → {1,1,1}로 수정
     - 원인 2 : Canvas-Main이 Screen Space - Camera 모드인데 AimCursor.cs
       가 rectTransform.position에 마우스 스크린 픽셀 좌표를 그대로
       대입하고 있었음(Overlay 모드에서만 맞는 방식) → Camera 모드에서도
       맞게 RectTransformUtility.ScreenPointToLocalPointInRectangle로
       변환하도록 수정

  2. 조작 방식 구체화 (로드맵 문서 갱신, 12.54)
     - "카타나 제로(Katana Zero) 모티브 : WASD 이동 + 마우스로 공격
       위치/방향 지정 + 클릭 공격" 확정
     - 단, 카타나 제로는 방 단위 던전 구조인 반면 이 프로젝트는 던전
       없이 곧바로 보스전으로 진입하는 구조라는 차이점도 명시
     - Assets/Docs/1. Plan/ 파일명 타임스탬프를 19.38 → 12.54로 갱신
       (문서 관리 규칙에 따라 파일명만 새로 만들고 제목은 유지)

  3. 클릭 공격 판정 최초 구현
     - AvoidInput.inputactions에 "Attack" 액션(<Mouse>/leftButton) 추가
     - IDamageable.cs(TakeDamage 인터페이스) 신규
     - PlayerAttack.cs 신규 : 클릭 시 마우스 스크린 좌표를 Player와
       같은 z 평면 월드 좌표로 변환(Camera가 Perspective라 Ray-Plane
       교차 필요) → 조준 방향 계산 → 사거리(attackDistance) 끝에
       반지름(attackRadius) 원형 판정(OverlapCircleAll) → enemyLayer +
       IDamageable 대상에게 데미지
     - ProjectSettings/TagManager.asset 9번 레이어를 "Enemy"로 신규
       지정, Player에 PlayerAttack 부착 + enemyLayer 연결

  4. 공격 판정 확인용 보강 ([2. ChangePlan] → [3. ChangeCompleted]
     절차로 진행, 14.28 → 14.44)
     - 요구사항 : Enemy1/2/3(맞으면 사라짐+콘솔 로그), 클릭 시
       Player 밑 AttackEffect가 Player 중심에서 사거리만큼 뻗어 나왔다가
       인스펙터에서 조절 가능한 시간 뒤 사라짐, 방향은 클릭 방향
     - 실행 전 계획서 c절과 실제 씬을 대조하던 중, 사용자가 이미
       에디터에서 Enemy1/2/3와 Player 자식 "Body"/"Square"를 직접
       만들어 둔 상태였음을 발견 → 절차대로 변경을 중지하고 계획서에
       차이점(i절)을 기록한 뒤 사용자에게 확인
     - 확인 결과 : Enemy1/2/3와 "Square"(→ AttackEffect로 재활용)는
       기존 오브젝트를 그대로 재사용, "Body"는 나중에 캐릭터를 넣을
       자리로 미리 만들어 둔 것이라 이번 범위에서 건드리지 않기로 함
     - Enemy.cs(IDamageable 구현, 피격 시 로그+Destroy) 신규, PlayerAttack.cs
       에 attackEffectTransform/attackEffectRenderer/effectDuration
       필드와 ShowAttackEffect/HideEffectAfterDelay(코루틴) 추가
     - 씬 반영 : Enemy1/2/3 Layer→Enemy + CircleCollider2D(Trigger)
       + Enemy.cs 부착, "Square"→"AttackEffect" 이름 변경 후 시작 시
       비활성화, PlayerAttack 필드 연결(effectDuration 기본 1초)
