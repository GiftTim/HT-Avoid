[해결한 문제]

  1. 타일맵이 z = 1 이 아니면 게임 화면에 안 보임
     - 원인 : Main Camera 가 z = 0, Near Clip 0.3 → 같은 z = 0 에 있는
       타일맵이 잘림
     - 해결 : Main Camera 를 z = -10 으로 (2D 기본값)

  2. @GamePlay / @Camera 가 Screen Space - Overlay Canvas 였음
     - Overlay Canvas 는 해상도에 따라 위치/스케일이 자동으로 바뀌어
       게임 오브젝트·카메라의 월드 좌표가 해상도마다 달라짐.
       @ Environment (960,540) / $Grid (-960,-540) 는 이걸 맞추던 값
     - 정리 후 (사용자가 에디터에서 작업) : @Gameplay, @Camera 를 빈
       오브젝트로, Main Camera (0,0,-10), @ Environment / $Grid (0,0,0)

  3. 정리 후 타일맵과 Player 가 같이 안 보임
     - 원인 : 타일이 $Grid 가 (-960,-540) 이던 때 칠해져서 칸 좌표가
       (958~962, 538). Grid 를 원점으로 옮기자 화면 밖으로 감
     - 해결 : 원점 근처에 다시 칠하기 (또는 Select/Move 툴로 이동)

  4. Player 를 클릭해도 타일맵이 선택됨
     - 하이어라키의 Scene Picking(손가락) 아이콘으로 타일맵 선택 잠금

  5. 프로젝트 설정 : 레이어 UI - Live3D / Player 추가, Sorting Layer
     순서 Default → Background → NPC → Player → Foreground
