b. 요구한 기능
================================================================

  26.10.07 Record 의 "그 다음 : 작은 디테일" 2건.

  1. VN ↔ 피하기 사이 로딩창 (헬테이커 참고)
  2. 패배 후 "어느 정도 길이에서 패배했는지" 표시 (컵헤드 참고)

  완료 조건 :
  (1) [startAvoid] 로 들어갈 때, 그리고 피하기에서 VN 으로 돌아올 때
      장면이 뚝 끊기지 않고 로딩창(가림막)이 덮은 상태에서 전환됨
  (2) 시간 초과 재도전 때도 씬 내렸다 올리는 동안 가림막이 덮임
  (3) 시간 초과 시 "TIME OVER" 와 함께 도달 비율(예: 62%)이 표시됨
  (4) 위 둘 모두 키보드/패드 조작만으로 동작 (마우스 불필요)

  범위 밖 :
  - 로딩창 그림/연출의 최종 디자인 (지금은 단색 가림막 + 임시 글자)
  - 실패 화면의 그림/애니메이션 (지금은 임시 글자)

c. 현재 상황 및 코드
================================================================

  [ 씬 전환 흐름 ]
  - CMD_DatabaseExtension_Avoid.StartAvoid : VN 숨김 -> VN 입력 끔 ->
    AvoidSession.Begin -> Avoid 씬 Additive 로드 -> IsFinished 대기 ->
    ReturnToVN (Avoid 언로드 -> VN 입력 켬 -> VN 표시)
  - GameController.TimeOverRoutine : 1.5초 "TIME OVER" -> AvoidSession.
    NotifyRetry -> ReloadAdditive (언로드 후 다시 Additive 로드)
  - 세 곳 모두 가림막 없이 바로 전환 -> 로드 중 빈 화면/끊김이 그대로 보임

  [ 패배 지점 데이터 ]
  - AvoidSession.LastProgress(0~1) / LastPatternsLeft 가 이미 기록됨
    (GameController.TimeOverRoutine 이 NotifyRetry 로 넘김)
  - 아직 화면에 보여주는 코드는 없음. UIController.ShowMessage 는 한
    덩어리 문구만 지원


================================================================
d. 요구한 기능을 만들기 위해서 어떤 식으로 생성하거나 변경해야 하는지
================================================================

  ■ 로딩창 : ScreenFader (새 스크립트, DontDestroyOnLoad 캔버스)
    - 최상단 정렬 순서의 전체 화면 검은 Image + CanvasGroup 을 코드로 생성
    - FadeOut(시간) : 투명 -> 불투명, FadeIn(시간) : 불투명 -> 투명
    - 어느 씬에도 속하지 않으므로 Avoid 를 언로드해도 살아 있음
    - 임시 글자 "LOADING..." 을 가운데에 표시 (나중에 그림으로 교체)
    - 호출 위치 :
      · StartAvoid : VN 숨기기 전 FadeOut -> 로드 -> 로드 끝나고 FadeIn
      · ReturnToVN : FadeOut -> 언로드 -> VN 표시 -> FadeIn
      · ReloadAdditive : FadeOut -> 언로드 -> 로드 -> FadeIn
    - 페이드 중에는 Avoid 시작(타이머)이 가림막 뒤에서 흐르지 않도록
      최소 표시 시간과 로드 완료를 함께 기다림

  ■ 패배 지점 표시 : UIController.ShowMessage 를 두 줄로 확장
    - ShowMessage(제목, 부제 = "") : 부제는 작은 글자
    - TimeOverRoutine 에서 "TIME OVER" + "62% 지점" 표시
    - 값은 이미 있는 Distance / goalDistance 를 사용 (AvoidSession 불필요)
    - (확장안) 진행 막대에 패배 지점 표시 — 미정, h절 참고

e. 다른 방법들 중에서 왜 d의 방식으로 만든 것인지
================================================================

  - 로딩창을 Avoid 씬 안에 두는 방법 : 그 씬이 내려가는 순간 같이
    사라지므로 전환 구간을 덮을 수 없다. 씬 밖(DontDestroyOnLoad)이어야 함
  - 로딩창을 VN 씬의 캔버스에 두는 방법 : VN 이 숨겨지는 구간과 겹치고
    Avoid 단독 Play 에서는 쓸 수 없다
  - 패배 지점을 AvoidSession 에서 읽는 방법 : 같은 값이 GameController 에
    이미 있고 표시 시점이 같은 클래스라 거칠 필요가 없다. 나중에 VN 대사나
    별도 실패 화면에서 쓰게 되면 그때 LastProgress 를 읽는다

h. 주의할 점 / 미정 사항
================================================================

  - 페이드 시간을 길게 잡으면 시간 초과 재도전(헬테이커식 즉시 재도전)의
    템포가 느려진다. 재도전은 짧게(0.2~0.3초), 챕터 진입/복귀는 조금 더
    길게(0.5초 안팎) 분리하는 것을 제안
  - 에디터에서는 씬 로드가 거의 즉시라 로딩창이 깜빡임으로만 보일 수 있음.
    빌드에서 체감이 크다
  - 페이드 중 입력 처리 : 가림막은 입력을 막지 않지만, 전환 중 Space 연타가
    VN 에 들어가지 않도록 기존 SetInputEnabled 흐름 유지

  [ 미정 — 사용자 확인 필요 ]
  - 로딩창 스타일 : 검은 페이드 / 챕터 제목 카드 / 캐릭터 일러스트
  - 시간 초과 재도전에도 로딩창을 넣을지(빠른 페이드) 아니면 넣지 않을지
  - 패배 지점 표시 형태 : 퍼센트 글자만 / 진행 막대 위 마커 / 남은 거리(m)
