b. 요구한 기능
================================================================

  가속할 때, 가속했다는 느낌이 들도록 캐릭터 주위에 이펙트를 넣는다.

  - 대상 씬 : Assets/Scenes/Avoid.unity
  - 참고 계획 : [26.10.02_20.12] 3-b 다가오는 공격, 피격 반응, 타이머·거리 UI
                (StageSpeed 구조 / 가속은 GameController 의 acceleration)

  완료 조건 : Avoid.unity 단독 Play 에서
  (1) 앞 방향키를 누르고 있으면 가속이 쌓이는 만큼 캐릭터 주변에
      바람 줄기가 늘어남
  (2) 앞 방향키를 떼거나 피격되어 가속이 초기화되면 줄기가 부드럽게
      사라짐
  (3) 캐릭터가 좌우로 움직이면 줄기가 꼬리처럼 남음
  (4) 줄기가 캐릭터를 가려 피하기 판단을 방해하지 않음
  (5) 콘솔에 에러/경고가 없음

  범위 밖 : 효과음/BGM 변화, 캐릭터 스프라이트 자체의 변형(잔상 등),
  점프/피격 이펙트

c. 현재 상황 및 코드
================================================================

  ※ 이번 세션(26.10.03)에 실제 파일을 읽어 확인한 내용

  [ 가속 로직 — GameController.cs ]
  - moveSpeed(10) → maxSpeed(20) 까지 acceleration(1.5/초) 로 증가
  - 앞 방향키를 놓거나 피격되면 cruiseSpeed 가 moveSpeed 로 초기화
  - AccelerationRatio (0~1) 를 공개 : 가속이 쌓인 정도.
    "가속 연출이 읽는다"고 주석에 명시돼 있음 → 연출은 이 값만 읽으면 됨

  [ 이미 존재하는 연출 스크립트 ] (파일 수정 시각 2026-10-03 오후 10시대)
  - PlayerSpeedAura.cs (22:42) : 캐릭터 둘레 원형에서 앞→뒤로 스쳐
    지나가는 바람 줄기. 코드로 ParticleSystem 을 만들어 캐릭터 자식에
    붙임. 월드 공간 시뮬레이션이라 좌우 이동 시 꼬리가 남음.
    AccelerationRatio 로 방출량 조절
  - SpeedEffect.cs (22:33) : 화면 가장자리 속도선 + 카메라 FOV 확대.
    카메라 자식에 붙는 방식

  [ 씬 연결 상태 — Avoid.unity ]
  - PlayerSpeedAura : Player 오브젝트에 이미 부착됨 (인스펙터 기본값)
  - SpeedEffect : 씬에 연결돼 있지 않음 (guid 가 씬 파일에 없음)

  → 즉 "캐릭터 주위 이펙트"의 코드와 씬 연결은 이미 되어 있음.
    이 세션에서 새로 작성한 것은 아니며, Play 로 확인된 기록도 아직 없음.

d. 요구한 기능을 만들기 위해서 어떤 식으로 생성하거나 변경해야 하는지
================================================================

  ■ 구조 : 연출은 AccelerationRatio 만 읽는 "구경꾼"
    - 게임 로직(GameController)은 건드리지 않고, 연출 스크립트가
      매 프레임 AccelerationRatio 를 읽어 방출량을 조절
    - strength 를 MoveTowards 로 따라가게 해 켜질 때/꺼질 때 부드럽게

  ■ 기본 방침 : 새 코드를 쓰기 전에 기존 PlayerSpeedAura 를 Play 로
    보고 부족한 점만 보강한다
    1) Play 로 (1)~(5) 확인
    2) 확인 결과에 따라 인스펙터 값 조정만으로 해결되면 코드 수정 없음
       (maxEmissionRate / ringRadius / streakColor / smoothSpeed 등)
    3) 값 조정으로 부족하면 보강 후보 (필요한 것만):
       - 캐릭터 발밑 먼지/바닥 흔적
       - 캐릭터 뒤로 끌리는 트레일
       - 가속 최대 시 바람 줄기 색/길이 변화
    4) 화면 전체 연출이 더 필요하면 SpeedEffect(속도선 + FOV)를
       카메라에 추가로 부착 (코드는 이미 있음)

e. 다른 방법들 중에서 왜 d의 방식으로 만든 것인지
================================================================

  [ 연출 위치 : 캐릭터 자식 vs 카메라 자식 ]
  - 캐릭터 자식 (이번 요구) : "캐릭터 주위"라는 요구에 직접 대응.
    캐릭터와 함께 좌우로 움직이고 월드 공간 시뮬레이션으로 꼬리가 남음
  - 카메라 자식 (SpeedEffect) : 화면 가장자리 속도선이라 전체 속도감에는
    좋지만 캐릭터가 "가속했다"는 느낌은 약함 → 보조로 병행 가능

  [ 이펙트 구현 : 코드로 ParticleSystem 생성 vs 파티클 프리팹/에셋 ]
  - 코드 생성 (현행) : 별도 에셋 없이 바로 동작, 수치를 인스펙터에서
    조정 가능. 그림 리소스가 정해지는 시점(4일차 이후)에 프리팹으로
    교체해도 AccelerationRatio 를 읽는 구조는 그대로 유지됨

  [ 가속량 전달 : 연출이 GameController 를 직접 읽음 vs 이벤트 ]
  - 직접 읽기 (현행) : GameController 는 한 판에 하나뿐이고
    AccelerationRatio 가 이미 0~1 로 정규화되어 있어 가장 단순.
    GameController 가 없는 씬에서도 0 으로 처리되어 에러가 나지 않음

f. 어떤 순서로 진행할 것인지
================================================================

  1. (에디터) Unity 로 돌아가 Avoid.unity Reload → 컴파일 에러 확인
  2. (검증) Avoid.unity 단독 Play : 앞 방향키를 누른 채 가속 →
     b절 완료 조건 (1)~(5) 확인
  3. (튜닝) 부족하면 Player 의 PlayerSpeedAura 인스펙터 값 조정
  4. (필요 시) d절 3) 보강 후보 중 필요한 것만 추가,
     SpeedEffect 를 카메라에 부착할지 결정
  5. 이상 없으면 이 문서를 3. ChangeCompleted 로 이동, Record 작성

g. 어디가 어떤 식으로 변경되는지
================================================================

  [ 이미 존재하는 파일 ] (Assets/Scripts/Avoid/Core/)
  - PlayerSpeedAura.cs : 캐릭터 주변 바람 줄기 (Player 에 부착됨)
  - SpeedEffect.cs : 화면 속도선 + FOV (씬 미연결)

  [ 수정 예정 ]
  - 기본은 Avoid.unity 의 Player > PlayerSpeedAura 인스펙터 값만 조정
  - 보강이 필요하면 PlayerSpeedAura.cs 에 모듈 추가 (d절 3)

  [ 변경 없음 ]
  - GameController.cs 의 가속 로직 (AccelerationRatio 만 읽음)
  - VN 엔진 전체, 입력 설정(AvoidInput)

h. 주의할 점
================================================================

  ■ 줄기가 캐릭터를 가리지 않게 : 생성 위치가 캐릭터 앞쪽(+Z) 원형
    테두리이고 안쪽은 비워 둠(ringThickness). 값을 키우면 캐릭터
    위로 겹쳐 시야를 방해할 수 있음 → 피하기 판에서는 연출보다
    가독성이 우선

  ■ 스프라이트와 정렬 : 파티클은 Sorting Layer/Order 가 아니라 깊이로
    정렬됨. 캐릭터 스프라이트보다 앞에 그려지는 줄기가 몸을 가리는지
    Play 에서 확인

  ■ 머티리얼 : Shader.Find("Universal Render Pipeline/Particles/Unlit")
    를 쓰므로 빌드에 셰이더가 포함되어야 함 (GroundGrid.mat 이 URP
    Unlit 을 써서 일부 포함되지만, 빌드 테스트 때 핑크색으로 보이지
    않는지 확인)

  ■ SpeedEffect 의 FOV 확대는 카메라 FOV 를 직접 바꿈 : 다른 코드가
    FOV 를 조정한다면 충돌하므로 부착 전에 확인

  ■ 연출 세기 수치는 전부 출발점 : 실제 화면을 보며 조정
