    실제와 다르지만, 문서 관리 규칙상 ChangePlan은 항목별 보관용이라

  ── 신규 파일: Assets/Scripts/VisualNovel/Core/Commands/Database/
     Extensions/CMD_DatabaseExtension_Avoid.cs ──────────────

  변경 전: (파일 없음)

  변경 후:
  ```csharp
  using DIALOGUE;
  using System;
  using System.Collections;
  using UnityEngine;
  using UnityEngine.SceneManagement;

  namespace COMMANDS
  {
      public class CMD_DatabaseExtension_Avoid : CMD_DatabaseExtension
      {
          private const string AVOID_SCENE_NAME = "Avoid";

          new public static void Extend(CommandDatabase database)
          {
              database.AddCommand("startAvoid", new Func<string[], IEnumerator>(StartAvoid));
              database.AddCommand("endAvoid", new Func<string[], IEnumerator>(EndAvoid));
          }

          private static IEnumerator StartAvoid(string[] data)
          {
              yield return DialogueSystem.instance.Hide(0f, true);

              yield return SceneManager.LoadSceneAsync(AVOID_SCENE_NAME, LoadSceneMode.Additive);

              Debug.Log("[CMD_DatabaseExtension_Avoid] Avoid 씬 로드 완료");
          }

          private static IEnumerator EndAvoid(string[] data)
          {
              yield return SceneManager.UnloadSceneAsync(AVOID_SCENE_NAME);

              yield return DialogueSystem.instance.Show(0f, true);
          }
      }
  }
  ```

  [ 변경 후 작동 흐름 ]

  1. CommandManager.Awake()가 리플렉션으로 CMD_DatabaseExtension 하위
     타입을 전부 스캔 → CMD_DatabaseExtension_Avoid.Extend()가 자동
     호출되어 "startAvoid"/"endAvoid" 명령이 CommandDatabase에 등록됨
     (수동 등록 불필요, CLAUDE.md에 적힌 구조 그대로)

  2. 에디터 Play 모드로 VisualNovel.unity 진입 → TestDialogueFiles.
     Start()가 fileToRead(이제 AvoidRoundTripTest.txt)를 읽어
     VNManager를 통해 대화를 자동 시작

  3. 첫 줄 "피하기로 진입합니다" 대사 출력 + 같은 줄에 있는
     `[wait]startAvoid()` 파싱 → 대사가 다 출력된 뒤 사용자 입력을
     받으면 LINE_RunCommands 실행
     - DL_COMMAND_DATA.RipCommands가 `[wait]` 접두어를 보고 이름에서
       떼어낸 뒤 waitForCompletion=true로 설정 → ConversationManager가
       완료까지 대기하도록 분기
     - StartAvoid 코루틴 실행 : DialogueSystem.Hide(0,true)로 대화창
       즉시 숨김 → SceneManager.LoadSceneAsync("Avoid", Additive)가
       끝날 때까지 대기 → 로그 출력
     - Avoid 카메라(Depth 1)가 VN 카메라들(Depth 0 이하)보다 나중에
       그려져 화면 전체가 Avoid 씬으로 전환됨. VN 씬은 언로드되지
       않으므로 DialogueSystem/CharacterManager 등 VN 싱글톤은 계속
       생존

  4. 중간 줄(`[wait]endAvoid()`, 대사 없음)은 사용자가 입력(Enter
     권장 — Space는 Avoid의 Jump와 충돌하므로 피할 것, h절 참고)해서
     진행시켜야 실행됨. 실행되면:
     - SceneManager.UnloadSceneAsync("Avoid") 완료까지 대기 → Avoid
       씬 언로드
     - DialogueSystem.Show(0,true)로 대화창 복귀

  5. 마지막 줄 "VN으로 복귀했습니다" 대사 출력
